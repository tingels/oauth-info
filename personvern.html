Personvernerklæring

Sist oppdatert: 16. september 2026

Gwynevere er et privat, egenutviklet automasjonsverktøy som brukes av én enkeltperson på sin egen datamaskin. Denne erklæringen beskriver hvordan verktøyet behandler data fra Google-kontoen din.

1. Hvilke opplysninger behandles

Når du gir verktøyet tilgang til Google-kontoen din, kan det lese:

  • e-postmeldinger og tilhørende metadata som avsender, emne og dato
  • vedlegg knyttet til disse meldingene

Verktøyet kan også merke e-post som lest. Det oppretter ikke, endrer eller sletter innhold i kontoen din.

2. Formål

Opplysningene brukes utelukkende til å lage et personlig daglig sammendrag for eieren av kontoen — for eksempel oversikt over arbeidsplan og båtanløp.

3. Behandlingsgrunnlag og lagring

All behandling skjer lokalt på eierens egen datamaskin. OAuth-tokenet lagres lokalt på samme maskin, beskyttet av filsystemets tilgangskontroll. Ingen data lagres på servere utenfor eierens eget utstyr.

4. Deling med tredjeparter

Opplysningene deles ikke med noen tredjepart. De selges ikke, brukes ikke til annonsering, og brukes ikke til å utvikle eller trene maskinlæringsmodeller.

5. Bruk av data fra Google API

Verktøyets bruk av informasjon mottatt fra Google API-er følger Google API Services User Data Policy, inkludert kravene til begrenset bruk (Limited Use).

6. Dine rettigheter

Du kan når som helst trekke tilbake tilgangen ved å fjerne verktøyet under sikkerhetsinnstillingene i Google-kontoen din. Du kan også be om innsyn i eller sletting av opplysningene som er lagret lokalt.
